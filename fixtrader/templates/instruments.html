How to add symbols and send an order
  1. Connect both FIX sessions on the Connection page.
  2. Enter the exchange and product, such as CME and ES. Choose Futures, Options or Listed spreads, then Search Stellar.
  3. Match the contract description and expiry. Click Add + subscribe to save its unique Stellar Security ID and receive prices.
  4. Click Buy or Sell in the watchlist. Check account, quantity, order type and time in force. Enter a limit and/or stop trigger when required.
  5. Review the exact ticket and confirm Send UAT order. Follow the Stellar acknowledgement and execution reports below.
  6. Cancel requests wait for Stellar. Replace changes total order quantity and prices, not just the remaining quantity.
  7. For filled orders, use Close position to review an opposite-side market order for the remaining local fills. Confirm the position is still open in Stellar before sending.

Product symbols are not unique contracts: ES can describe many expiries. Select an exact returned instrument instead of guessing an ID. Zero or negative prices are valid for some spread instruments.

Stellar accepts MARKET, LIMIT, STOP and STOP LIMIT, DAY / GTC / IOC / FOK; what each exchange accepts varies. See the Stellar FIX Order Router specification.
